# Fundamentos de JavaScript

El objetivo principal de la práctica es analizar, identificar y simular mediante código JavaScript (ES6+) la lógica de negocio y las funcionalidades detrás de una plataforma de comercio electrónico como **Amazon**.
## Fundamentos - Funciones - Objetos (Defaz Leonardo)
En esta sección se presentan los ejercicios de lógica, en donde se identifican los componentes y funcionalidades básicas que posee la compra de unos guantes de boxeo.

Link del producto: https://acesse.one/8209cne

Los ejercicios que abarca esta temática van desde el archivo 1 hasta el 14.

## Arreglos - Manipulación del DOM - Asincronismo (Estrada Anderson)
En estos ejercicios se usan los arreglos para el manejo del catálogo, la manipulación de los elementos de la página y el manejo de procesos asincrónicos para la simulación de carga en tiempo real.

Link del catálago: https://acesse.one/fqb0qhb

Los ejercicios abarcados van desde el 15 hasta el 28.

## Api - Local Storage - Módulos (Chasi Alexis)
Para la extracción de los datos se usó una API pública de https://rickandmortyapi.com/api/character/8 para identificar los datos relevantes que podrían ir en un e-commerce.

Para el almacenamiento local se hizo uso de la API https://fakestoreapi.com/products/2 en donde se extrajeron los datos que son necesarios almacenar de una precompra (añadir al carrito).

Los módulos nos permiten separar el código en diferentes archivos y usarlos cuando sea necesario. Se separó la lógica y las funciones a la hora de simular la venta. Los datos almacenados se basan en el siguiente producto: https://acesse.one/fqb0qhb
